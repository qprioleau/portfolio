Preau Tech Solutions Portfolio Website

A futuristic HUD-inspired portfolio and business website developed for Preau Tech Solutions, LLC.
This project showcases technical capabilities in secure software development, automation engineering, SaaS architecture, and mobile application development.

Designed and developed by Quincy Prioleau using Python, Flask, custom CSS, and modern responsive frontend design principles.

Live Features:
* Futuristic HUD-inspired UI
* Glassmorphism interface design
* Responsive portfolio layout
* Bootstrap carousel project showcase
* Contact form integration
* Custom CSS animations and glow effects
* Flask templating with reusable base layouts
* Mobile-friendly responsive design
* Project showcase for web and mobile applications

Design Philosophy:
The website was designed around a futuristic HUD (Heads-Up Display) aesthetic combining:

* Glassmorphism
* Cybersecurity-inspired visuals
* Technical typography
* Neon cyan interface accents
* Transparent layered panels
* Animated grid overlays

The goal was to create a modern technical startup appearance that reflects advanced engineering, security, and software development capabilities.
